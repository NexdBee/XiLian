笔记本怎么开服务

  1. 在项目目录执行 npm install，然后 npm run bank。
  2. 浏览器打开本机提示的局域网地址，确认题目数量。
  3. 把新 JSON 丢进 bank/drop/ 或在服务页上传，再让手机拉取。
